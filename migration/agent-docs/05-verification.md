# Verification log

How the MyST build was checked against the Sphinx site, and the results. Scripts:
`migration/verify.py` (structural + output audit) and `migration/checks/*.py`
(browser probes). Baseline = live site `https://docs.maap-project.org/en/latest/`
plus a local Sphinx build of `develop` (0dcbe21) with pandoc 3.11.

## 2026-09-11: full build of the migrated tree

- `make build`: 110 pages built, 109 redirect stubs written (root `index.html` stays).
- `make verify`: every old Sphinx URL (110) maps to a built page and has a stub;
  every toc entry built; build log has no unknown directives / unexpected options /
  missing files; **output audit: 0 notebooks with output differences** (for every
  notebook, the set of stored outputs by MIME type in the `.ipynb` equals the output
  nodes in the built page JSON).
- Determinism: after `make migrate` (restore `docs/source` from `develop`, wipe,
  regenerate) the tree hash is identical to the previous run (see the session log
  below for the hash values).
- Build warnings (17): listed and explained in `02-decisions.md` ("Warnings left in
  the build log on purpose"); none affects rendering.
